# MIMI for Codex

`mimi-pet-v2.zip` is the local MIMI pet package. The unpacked package is in
`mimi/`, with pet ID `mimi` and the original MOMO package's v2 manifest format.

The artwork comes directly from MIMI-Offline 2.0.0. The original face, head
angle, expression, animation order and sixteen look poses are preserved.
All 74 source cells use the same resize and padding to fit the GPT package
geometry. No regenerated idle artwork is included.

- [Current package](mimi-pet-v2.zip)
- [Animation previews](mimi/previews/)
- [Source preservation checks](mimi/validation.json)
- [Archived scripts and artwork decision](../archive/supporting-files-2026-11-13/GPT-Assets/README.md)

For the standalone Windows companion, run `MIMI.exe` in `../MIMI-Offline`.
The Offline applications and their release files have not been changed.

This is a personal project, made just for fun.
