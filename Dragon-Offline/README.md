# Dragon Offline 2.0.0

Exit a running older Dragon from its right-click menu first, then double-click
`Dragon-Offline.exe`. Windows 10/11 x64; no installation, R,
RStudio, .NET or internet connection is needed. The artwork and icon are
embedded in the EXE, so it can be moved on its own.

This edition keeps the approved simplified adult anime design and a calm,
warm, slightly playful personality. The face is larger; costume decoration,
hair lines and tail scales are removed. Crescent horns, violet eyes,
lavender wings and the smooth white crescent tail remain distinctive.

- Drag to move Dragon.
- Click for a small palm greeting, smile and brief playful wink.
- Double-click for a graceful celebratory lift.
- Right-click for thinking, review, concern and recovery, pause, occasional
  gliding, cursor tracking, four sizes, always on top and exit.
- Open the EXE again to bring the same Dragon home.

Responses play once and return to calm idle. Automatic activity decisions
are spaced 45–90 seconds apart; half of the decisions leave Dragon quiet.
Automatic glides are short, less likely and slower than in version 1.0.
Cursor gaze waits for a stable direction before changing pose.

The animation contains 57 standard frames, sixteen gaze poses and one neutral
cell. `TEST-RESULTS.txt` records actual native runtime checks, including the
single greeting sequence and quiet interval. `SHA256SUMS.txt` identifies
the tested EXE. This personal build is unsigned and needs no administrator rights.

Settings remain separate from MOMO and MIMI and compatible with Dragon 1.0:
`%LOCALAPPDATA%\DesktopPetsLite\Dragon\preferences.ini`.
The program is a visual companion with no chat model, network feature,
telemetry or automatic startup registration.

The native engine is adapted from the existing MOMO/MIMI Lite source.
Build and asset scripts use R. Source, generated rows and review artifacts
are in the [archived source](../archive/supporting-files-2026-11-13/Dragon-Source/README.md).
For a rebuild, extract the [source ZIP](../archive/supporting-files-2026-11-13/Dragon-Source.zip),
which retains the original sibling folder layout.
