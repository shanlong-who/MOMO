# Dragon Offline 1.0.0

Double-click `Dragon-Offline.exe`. Windows 10/11 x64; no installation, R,
RStudio, .NET or internet connection is needed. Artwork and icon are embedded
in the EXE, so the EXE can be moved on its own.

- Drag to move Dragon.
- Click to wave; double-click to jump.
- Right-click for thinking, review and disappointment reactions, pause,
  wandering, cursor tracking, four sizes, always on top and exit.
- Open the EXE again to bring the same Dragon home.

Dragon has separate settings from MOMO and MIMI. Preferences are stored in
`%LOCALAPPDATA%\DesktopPetsLite\Dragon\preferences.ini`.
The program is an animated visual companion. It has no chat model,
network feature, telemetry or automatic startup registration.

The animation contains 73 frames, including sixteen gaze directions.
`TEST-RESULTS.txt` records native runtime checks. `SHA256SUMS.txt` identifies
the tested EXE. This personal build is unsigned and needs no administrator rights.

The native engine is adapted from the existing MOMO/MIMI Lite 2.0.0 source.
Build and asset scripts use R. See `../Dragon-Source` for reproducible source,
the original reference, generated rows and visual checks.
