# MIMI Lite 2.0.0

Double-click **MIMI.exe**. This is the current native desktop pet for
Windows 10/11 on Intel or AMD x64. No R, .NET, installation or internet
connection is required. MIMI has remastered fur, eyes and tabby markings.

Drag to move, click to say hello, double-click to jump, and right-click for
actions, sizes, preferences and exit. Opening the same EXE again brings MIMI
home. Preferences are stored in `%LOCALAPPDATA%\DesktopPetsLite\MIMI`.
