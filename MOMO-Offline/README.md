# MOMO Lite 2.0.0

Double-click **MOMO.exe**. This is the current native desktop pet for
Windows 10/11 on Intel or AMD x64. No R, .NET, installation or internet
connection is required. MOMO has no collar or pendant.

Drag to move, click to say hello, double-click to jump, and right-click for
actions, sizes, preferences and exit. Opening the same EXE again brings MOMO
home. Preferences are stored in `%LOCALAPPDATA%\DesktopPetsLite\MOMO`.
