This collection release brings together the GPT and standalone Offline
packages for MOMO, MIMI and Dragon, with direct downloads and one checksum file.
The native applications retain internal version **2.0.0**. The collection
version **2.1.0** identifies this combined release.

## Package details

- MOMO GPT uses the approved collar-free artwork. MIMI retains its released
  appearance. The existing collared MOMO is preserved in the repository archive.
- Dragon uses the approved simplified 2.0 design and its existing animations.
- All six ZIPs are copied unchanged from the verified project packages. The
  MOMO and MIMI Offline ZIPs are identical to their earlier v2.0.0 release assets.
- Offline packages run on Windows 10/11 x64 without R, RStudio, .NET installation
  or internet access. Extract the ZIP and run the included EXE.

For GPT installation details and source, see the corresponding product folder
in the [repository](https://github.com/shanlong-who/MOMO/tree/v2.1.0).
Original packages, source archives and validation history remain available there.
